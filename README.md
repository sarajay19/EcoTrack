# EcoTrack

شروع EcoTrack يعالج مشكلة التصحر التي تؤثر على 70% من أراضي المملكة، مهددةً الزراعة والموارد الطبيعية. يقدم المشروع حلولاً تعتمد على بيانات الأقمار الصناعية والذكاء الاصطناعي لدعم أهداف رؤية 2030.
